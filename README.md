# منصة الخدمات والعقارات (PSM)

خريطة عامة لفلسطين: الناس بتدوّر على خدمة (سبّاك، كهربجي، طبيب، فندق…) أو عقار، بتشوفه على الخريطة،
وبتطلب الخدمة وبتحكي مع صاحبها وبتقيّمه. أصحاب الخدمات بيحدّثوا حالتهم وموقعهم، والمدير بيدير كل شي من لوحة الإدارة.

الموقع: https://psm.alameenapps.com

---

## المشروع من جوّا — بكلام بسيط

المنصة أربع قطع شغّالة مع بعض:

| القطعة | شو بتعمل | وين |
|---|---|---|
| **الواجهة** (اللي بيشوفه الناس) | الصفحات، الخريطة، البحث، الدردشة، لوحة الإدارة | `web/` |
| **السيرفر** | تسجيل الدخول، الطلبات، الدردشة، الإشعارات، الصلاحيات | `server.js` |
| **قاعدة البيانات** (PostgreSQL) | المستخدمين، الخدمات، الطلبات، الرسائل، التقييمات | سيرفر منفصل |
| **GeoServer** | بيرسم نقاط الخدمات والعقارات على الخريطة | سيرفر منفصل |

## وين كل إشي

```text
README.md            ← هالملف (ابدأ من هون)
server.js            ← السيرفر كامل
web/                 ← الواجهة (React)
  src/features/      ← كل ميزة بمجلد: map (الخريطة) · search (البحث) · requests (الطلبات والدردشة)
                       admin-users · admin-dashboard · notifications · listing-submissions (أضف نشاطك) …
  src/locales/       ← كل نصوص الموقع: ar.json عربي · en.json إنجليزي
  public/            ← صور وأيقونات وأصوات
  e2e/               ← تجارب تلقائية بمتصفح حقيقي
database/            ← سكربتات SQL لتجهيز قاعدة جديدة (شرحها بـ database/README.md)
dev/                 ← نسخة تجريبية كاملة على جهاز المبرمج (قاعدة وحسابات تجريبية)
docs/                ← الوثائق (فهرسها بـ docs/README.md)
tools/               ← سكربت النشر على سيرفر الويندوز
.github/workflows/   ← النشر التلقائي: أي إضافة على main بتنبني وبتنفحص وبتنتشر لحالها
.env.example         ← قائمة الإعدادات اللي لازم تكون بملف .env على السيرفر (بدون قيم حقيقية)
```

## بدك تغيّر شي؟ — وين

| بدك… | وين |
|---|---|
| تغيّر نص ظاهر بالموقع | لوحة الإدارة ← «النصوص» (بدون مبرمج)، أو `web/src/locales/ar.json` |
| تضيف نوع خدمة جديد | مبرمج — الخطوات بـ [docs/dev/guide.md](docs/dev/guide.md) |
| تضيف أو تعدّل نقطة على الخريطة | المدير من الخريطة نفسها (أداة التعديل)، أو صاحب النشاط من «أضف نشاطك» وبعدها موافقة المدير |
| تغيّر دور مستخدم أو تربطه بخدمة | لوحة الإدارة ← «المستخدمين» |
| تبعت إشعار للناس | صفحة الإشعارات (للمدير) |

## التشغيل على جهاز مبرمج

```bash
dev/dev.sh db-up && dev/dev.sh seed && dev/dev.sh server   # قاعدة تجريبية + حسابات + السيرفر
cd web && npm install && npm run dev                       # الواجهة على http://localhost:5173
```

الحسابات التجريبية والتجارب التلقائية: [dev/README.md](dev/README.md).

## قواعد ثابتة

- **ممنوع** أي كلمة سر أو عنوان قاعدة بيانات حقيقي بأي ملف بالمشروع، لأنه المستودع عام. مكانها ملف `.env`
  على السيرفر بس (مستثنى من git).
- النشر بيصير لحاله لما ينضاف شي على `main`، فـ `main` لازم يضل شغّال دايمًا.
