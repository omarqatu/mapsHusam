# دليل التكوين (Configuration Guide)

## نظرة عامة

يقدم هذا المستند دليلاً شاملاً لجميع المعلمات القابلة للتكوين في منصة خريطة خدمات فلسطين. كل خيار تكوين موثق بقيمته الحالية وموقعه ووصفه والقيم المسموحة وتوصيات الإنتاج وتأثيره.

## التحقق من صحة التكوين

### التحقق عند بدء التشغيل

نفذ التحقق من صحة التكوين عند بدء التطبيق:

```javascript
function validateConfiguration() {
    const required = [
        'JWT_SECRET',
        'SESSION_SECRET',
        'POSTGRES_HOST',
        'POSTGRES_USER',
        'POSTGRES_PASSWORD'
    ];
    
    const missing = required.filter(key => !process.env[key]);
    
    if (missing.length > 0) {
        throw new Error(`تكوين مفقود مطلوب: ${missing.join(', ')}`);
    }
    
    // التحقق من صحة القيم الرقمية
    if (process.env.PORT && isNaN(parseInt(process.env.PORT))) {
        throw new Error('تكوين PORT غير صالح');
    }
    
    // التحقق من صحة القيم المنطقية
    const boolVars = ['ENABLE_HELMET', 'ENABLE_CORS', 'ENABLE_RATE_LIMITING'];
    boolVars.forEach(key => {
        if (process.env[key] && !['true', 'false'].includes(process.env[key])) {
            throw new Error(`تكوين ${key} غير صالح`);
        }
    });
}
```
