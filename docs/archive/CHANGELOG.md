# سجل التغييرات (Changelog)

سيتم توثيق جميع التغييرات البارزة لمنصة خريطة خدمات فلسطين في هذا الملف.

التنسيق مبني على [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)،
وهذا المشروع يلتزم بـ [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [غير منشور]

### تمت الإضافة
- نظام توثيق شامل في مجلد `/docs`
- PROJECT_OVERVIEW.md - نظرة عامة على المشروع وسير العمل التجاري
- SYSTEM_ARCHITECTURE.md - توثيق بنية النظام
- FRONTEND_GUIDE.md - دليل تطوير الواجهة الأمامية
- BACKEND_GUIDE.md - دليل تطوير الواجهة الخلفية
- API_DOCUMENTATION.md - توثيق كامل لنقاط نهاية واجهة برمجة التطبيقات
- DATABASE_SCHEMA.md - مخطط قاعدة البيانات والبنية
- GIS_MODULE.md - توثيق وحدة نظم المعلومات الجغرافية والخرائط
- USER_ROLES.md - أدوار المستخدمين والأذونات
- SECURITY_POLICY.md - سياسات وإرشادات الأمان
- CONFIGURATION.md - دليل إدارة التكوين
- ENVIRONMENT_VARIABLES.md - مرجع متغيرات البيئة
- PERFORMANCE.md - دليل تحسين الأداء
- DEPLOYMENT.md - إجراءات النشر
- LOGGING_MONITORING.md - دليل التسجيل والمراقبة
- ERROR_HANDLING.md - استراتيجيات معالجة الأخطاء
- TESTING_GUIDE.md - منهجيات الاختبار
- CODING_STANDARDS.md - معايير البرمجة وأفضل الممارسات

### تم التغيير
- تحسين معالجة الأخطاء في تدفق رد طلب الخدمة
- تحسين بنية حمولة حدث Socket.io
- إضافة تسجيل شامل لتصحيح الأخطاء

### تم الإصلاح
- إصلاح خطأ 500 Internal Server Error عندما يكون requestId غير معرف في رد طلب الخدمة
- إصلاح خطأ SQL في نقطة نهاية التعليقات المعلقة
- إصلاح ReferenceError للمتغيرات غير المعرفة في الواجهة الأمامية
- إصلاح عدم فتح صندوق المحادثة فوراً بعد قبول طلب الخدمة

## [1.0.0] - 2026-07-29

### تمت الإضافة
- الإصدار الأولي لمنصة خريطة خدمات فلسطين
- خريطة تفاعلية مع تكامل OpenLayers
- نظام طلب الخدمة مع إشعارات في الوقت الفعلي
- وظيفة المحادثة بين المستخدمين ومزودي الخدمة
- مصادقة المستخدم مع JWT
- التحكم في الوصول القائم على الأدوار (مستخدم، مزود، مسؤول)
- نظام التقييم والمراجعة
- تكامل GeoServer لخدمات WMS/WFS
- PostgreSQL مع PostGIS للبيانات المكانية
- Socket.io للاتصال في الوقت الفعلي
- واجهة أمامية React مع Vite
- واجهة أمامية قديمة بـ JavaScript العادي
- لوحة تحكم المسؤول لإدارة المستخدمين
- إحصائيات وتحليلات الخدمات
- تتبع نجاح المزود
- دعم متعدد اللغات (عربي/إنجليزي)

### الأمان
- المصادقة القائمة على JWT
- تشفير كلمة المرور bcrypt مع دعم الترحيل
- رؤوس أمان Helmet.js
- تكوين CORS
- تحديد المعدل لنقاط نهاية واجهة برمجة التطبيقات والمصادقة
- التحقق من صحة الإدخال
- منع حقن SQL عبر الاستعلامات المُعَلَّمة

### قاعدة البيانات
- قاعدة بيانات PostgreSQL مع امتداد PostGIS
- قاعدة بيانات الخدمات لبيانات المستخدم والخدمات
- قاعدة بيانات العقارات لبيانات العقارات
- فهارس مكانية للأداء
- أكثر من 20 جدول طبقة خدمة مع بيانات مكانية
- جداول إدارة المستخدمين
- تتبع طلبات الخدمة
- تخزين رسائل المحادثة
- نظام التقييم والمراجعة

### ميزات نظم المعلومات الجغرافية
- خريطة تفاعلية مع OpenLayers
- عرض طبقة WMS عبر GeoServer
- استعلامات ميزات WFS
- قدرات البحث المكاني
- استعلامات BBOX
- حسابات المسافة
- تحويلات الإحداثيات (EPSG:28191 إلى EPSG:4326)
- إدارة موقع المزود
- تصور طبقة الخدمة

### نقاط نهاية واجهة برمجة التطبيقات
- نقاط نهاية المصادقة (تسجيل، تسجيل الدخول، تغيير كلمة المرور)
- نقاط نهاية طلب الخدمة (إنشاء، رد، إلغاء، تأكيد)
- نقاط نهاية المحادثة (إرسال رسالة، الحصول على الرسائل)
- نقاط نهاية التقييم (إرسال تقييم، الحصول على التقييمات)
- نقاط نهاية إدارة المستخدمين (الحصول على المستخدمين، عمليات المسؤول)
- نقاط نهاية الإحصائيات (أحداث الخريطة، إحصائيات تفصيلية، ملخص)
- نقاط نهاية نظم المعلومات الجغرافية (البحث عن الميزات، الحصول على الإحداثيات، تحديث الميزات)
- نقاط نهاية الأدوات المساعدة (التحقق من حد الطلب)

- لوحة تحكم المستخدم
- تصميم متجاوب
- واجهة متعددة اللغات
