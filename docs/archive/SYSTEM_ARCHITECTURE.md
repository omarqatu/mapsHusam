# بنية النظام (System Architecture)

## نظرة عامة

تتبع منصة خريطة خدمات فلسطين (PSM) بنية ثلاثية الطبقات حديثة مع قدرات في الوقت الفعلي. النظام مصمم للتعامل مع البيانات المكانية، الاتصالات في الوقت الفعلي، وسير عمل طلب الخدمة المعقد مع الحفاظ على الأمان والأداء.

## بنية الواجهة الأمامية

### مجموعة التكنولوجيا

#### واجهة React الأمامية (الحديثة)
- **الإطار**: React مع Vite
- **أداة البناء**: Vite (HMR سريع)
- **المنفذ**: 5173 (أو 5174 إذا كان مشغولاً)
- **إدارة الحالة**: React hooks + الحالة المحلية
- **التوجيه**: التوجيه من جانب العميل (إذا تم تنفيذه)
- **الوقت الفعلي**: عميل Socket.io

#### الواجهة الأمامية القديمة
- **التكنولوجيا**: JavaScript العادي
- **مكتبة الخريطة**: OpenLayers
- **المنفذ**: 3000 (يقدمه Express)
- **المكونات**: ملفات JavaScript معيارية

### أنواع الأخطاء

- **أخطاء التحقق من الصحة**: 400 طلب سيء
- **أخطاء المصادقة**: 401 غير مصرح
- **أخطاء التفويض**: 403 ممنوع

- **أخطاء تحديد المعدل**: 429 طلبات كثيرة جداً
- **أخطاء الخادم**: 500 خطأ في الخادم الداخلي

## بنية القابلية للتوسع

### التوسع الأفقي

```
موازن الحمل
    │
    ├─→ مثيل Node.js 1
    │   ├─ خادم واجهة برمجة التطبيقات
    │   └─ Socket.io
    │
    ├─→ مثيل Node.js 2
    │   ├─ خادم واجهة برمجة التطبيقات
    │   └─ Socket.io
    │
    └─→ مثيل Node.js N
        ├─ خادم واجهة برمجة التطبيقات
        └─ Socket.io
```

### التوسع الرأسي

```
موارد الخادم
    ├─ وحدة المعالجة المركزية: المعالجة متعددة النواة
    ├─ ذاكرة الوصول العشوائي: زيادة الذاكرة
    ├─ التخزين: SSD لـ I/O أسرع
    └─ الشبكة: نطاق ترددي عالي
```

## قرارات البنية

### لماذا Express.js؟
- ناضج ومتبنى على نطاق واسع
- نظام بيئي واسع للبرمجيات الوسيطة
- أداء جيد
- سهل التوسع

### لماذا PostgreSQL + PostGIS؟
- قاعدة بيانات علائقية قوية
- قدرات مكانية ممتازة
- الامتثال لـ ACID
- مفتوح المصدر

### لماذا Socket.io؟
- اتصال ثنائي الاتجاه في الوقت الفعلي
- آليات تراجع تلقائية
- دعم الغرف
- تكامل سهل مع Express

### لماذا OpenLayers؟
- مكتبة خرائط قوية
- تدعم مسارات متنوعة
- دعم WMS/WFS
- قابلة للتخصيص

### لماذا JWT؟
- مصادقة عديمة الحالة
- قابلة للتوسع
- آمنة
- متبنى على نطاق واسع
