# متغيرات البيئة (Environment Variables)

## نظرة عامة

يقدم هذا المستند دليلاً شاملاً لجميع متغيرات البيئة المستخدمة في منصة خريطة خدمات فلسطين. تُستخدم متغيرات البيئة لتكوين سلوك التطبيق، اتصالات قاعدة البيانات، إعدادات الأمان، وتكاملات الخدمات الخارجية.

## ملف البيئة

### موقع الملف

- **التطوير**: `.env` (في جذر المشروع، ليس في git)
- **القالب**: `.env.example` (في git للمرجع)

### تحميل متغيرات البيئة

يستخدم التطبيق `process.env` للوصول إلى متغيرات البيئة:

```javascript
const PORT = process.env.PORT || 3000;
const JWT_SECRET = process.env.JWT_SECRET;
```

## تكوين الخادم

### NODE_ENV

**الوصف**: وضع بيئة Node.js

**القيمة الحالية**: غير محدد (الافتراضي هو التطوير)

**القيم المسموحة**:
- `development`: وضع التطوير مع تسجيل التصحيح
- `production`: وضع الإنتاج مع إعدادات محسنة

**توصية الإنتاج**: `production`

**التأثير**:
- يؤثر على إبلاغ الأخطاء
- يؤثر على تفصيل التسجيل
- قد يؤثر على تحسينات الأداء

**موقع الملف**: `.env`

```env
NODE_ENV=production
```

### HOST

**الوصف**: عنوان مضيف الخادم

**القيمة الحالية**: `0.0.0.0`

**القيم المسموحة**:
- `0.0.0.0`: الاستماع على جميع الواجهات
- `127.0.0.1`: الاستماع فقط على localhost
- IP محدد: الاستماع على واجهة محددة

**توصية الإنتاج**: `0.0.0.0` (خلف الوكيل العكسي)

**التأثير**:
- يحدد واجهات الشبكة التي تقبل الاتصالات
- اعتبار أمني للخوادم العامة

**موقع الملف**: `.env`

```env
HOST=0.0.0.0
```

### PORT

**الوصف**: رقم منفذ الخادم

**القيمة الحالية**: `3000`

**القيم المسموحة**: 1024-65535 (نطاق المنفذ الصالح)

**توصية الإنتاج**: `3000` (أو كما تم تكوينه بواسطة الوكيل العكسي)

**التأثير**:
- يحدد المنفذ الذي يستمع إليه الخادم
- يجب أن يتطابق مع تكوين الوكيل العكسي
- يجب أن يكون متاحاً وغير مستخدم

**موقع الملف**: `.env`

```env
PORT=3000
```

### TRUST_PROXY

**الوصف**: إعدادات الثقة بالوكيل لـ Express

**القيمة الحالية**: `1`

**القيم المسموحة**:
- `0`: لا تثق بالوكيل
- `1`: ثق بالوكيل الأول
- `true`: ثق بجميع الوكلاء

**توصية الإنتاج**: `true` (خلف الوكيل العكسي)

**التأثير**:
- يؤثر على اكتشاف IP العميل
- يؤثر على تحديد المعدل
- مهم لرؤوس الأمان

**موقع الملف**: `.env`

```env
TRUST_PROXY=1
```

## تكوين قاعدة البيانات

### POSTGRES_HOST

**الوصف**: مضيف قاعدة بيانات PostgreSQL

**القيمة الحالية**: `localhost` (في التطوير) / `144.91.84.168` (في الإنتاج)

**القيم المسموحة**: اسم مضيف صالح أو عنوان IP

**توصية الإنتاج**: استخدم مضيف قاعدة بيانات خاص بالبيئة

**التأثير**:
- يحدد نقطة نهاية اتصال قاعدة البيانات
- يؤثر على زمن استجابة الاتصال
- حرج لعملية التطبيق

**موقع الملف**: `.env`

**مثال التطوير**:
```env
POSTGRES_HOST=localhost
```

**مثال الإنتاج**:
```env
POSTGRES_HOST=144.91.84.168
```

### POSTGRES_PORT

**الوصف**: منفذ قاعدة بيانات PostgreSQL

**القيمة الحالية**: `5432`

**القيم المسموحة**: 1-65535 (نطاق المنفذ الصالح)

**توصية الإنتاج**: `5432` (منفذ PostgreSQL الافتراضي)

**التأثير**:
- يجب أن يتطابق مع تكوين خادم PostgreSQL
- مطلوب لاتصال قاعدة البيانات

**موقع الملف**: `.env`

```env
POSTGRES_PORT=5432
```

### POSTGRES_USER

**الوصف**: اسم مستخدم قاعدة بيانات PostgreSQL

**القيمة الحالية**: غير محدد في `.env.example`

**القيم المسموحة**: اسم مستخدم PostgreSQL صالح

**توصية الإنتاج**: استخدم اسم مستخدم قوي وفريد

**التأثير**:
- مطلوب لمصادقة قاعدة البيانات
- يجب أن يكون لديه أذونات مناسبة

**موقع الملف**: `.env`

```env
POSTGRES_USER=your_db_user
```

### POSTGRES_PASSWORD

**الوصف**: كلمة مرور قاعدة بيانات PostgreSQL

**القيمة الحالية**: غير محدد في `.env.example`

**القيم المسموحة**: سلسلة كلمة مرور قوية

**توصية الإنتاج**: استخدم كلمة مرور قوية مُنشأة عشوائياً

**التأثير**:
- حرج لأمان قاعدة البيانات
- يجب الحفاظ عليه سرياً
- يجب تدويره بانتظام

**موقع الملف**: `.env`

```env
POSTGRES_PASSWORD=your_db_password
```

### SERVICES_DB_NAME

**الوصف**: اسم قاعدة بيانات الخدمات

**القيمة الحالية**: `services_db`

**القيم المسموحة**: اسم قاعدة بيانات PostgreSQL صالح

**توصية الإنتاج**: ابقِ كـ `services_db` للاتساق

**التأثير**:
- يجب أن يتطابق مع اسم قاعدة البيانات الفعلي
- يُستخدم للبيانات المتعلقة بالخدمات

**موقع الملف**: `.env`

```env

```

### REAL_ESTATE_DB_NAME

**الوصف**: اسم قاعدة بيانات العقارات

**القيم المسموحة**: اسم قاعدة بيانات PostgreSQL صالح

## تكوين CORS

### ALLOWED_ORIGINS

**الوصف**: قائمة مفصولة بفواصل للمصادر المسموح بها لـ CORS

**القيمة الحالية**: غير محدد (يسمح بجميع المصادر مع تحذير)

**القيم المسموحة**: قائمة مفصولة بفواصل من عناوين URL صالحة

**توصية الإنتاج**: حدد النطاقات المسموح بها

**التأثير**:
- يتحكم في الوصول عبر المصادر
- إعداد أمان حرج
- إذا لم يتم تعيينه، يسمح بجميع المصادر (غير آمن)

**موقع الملف**: `.env`

**مثال التطوير**:
```env
ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5173
```

**مثال الإنتاج**:
```env
ALLOWED_ORIGINS=https://psm.alameenapps.com,http://194.163.174.162:3000
```

### ALLOW_ALL_ORIGINS

**الوصف**: علامة السماح بجميع المصادر

**القيمة الحالية**: غير محدد في `.env.example`

**القيم المسموحة**: `true`، `false`

**توصية الإنتاج**: `false`

**التأثير**:
- إذا كان true، يتجاوز فحص المصدر
- خطر أمني في الإنتاج
- يجب استخدامه فقط في التطوير

**موقع الملف**: `.env`

```env
ALLOW_ALL_ORIGINS=false
```

## تكوين تحديد المعدل

### API_RATE_LIMIT

**الوصف**: الحد الأقصى لطلبات واجهة برمجة التطبيقات لكل نافذة

**القيمة الحالية**: `100`

**القيم المسموحة**: عدد صحيح موجب

**توصية الإنتاج**: `100` (اضبط حسب حركة المرور)

**التأثير**:
- يتحكم في معدل طلبات واجهة برمجة التطبيقات
- يمنع الإساءة
- منخفض جداً قد يحظر المستخدمين المشروعين

**موقع الملف**: `.env`

```env
API_RATE_LIMIT=100
```

**القيم المسموحة**: عدد صحيح موجب (مللي ثانية)

**توصية الإنتاج**: `900000` (15 دقيقة)

**التأثير**:
- يحدد نافذة وقت تحديد المعدل
- يؤثر على تجربة المستخدم
- يجب الموازنة بين الأمان وسهولة الاستخدام

**موقع الملف**: `.env`


**القيم المسموحة**: عدد صحيح موجب

**التأثير**:

- يمنع هجمات القوة الغاشمة
- منخفض جداً قد يحظر المستخدمين المشروعين

## أفضل ممارسات التكوين

### الأمان

1. **لا تلتزم أبداً بملف `.env`**: أضفه إلى `.gitignore`
2. **استخدم أسراراً قوية**: أسرار عشوائية طويلة
3. **دوران الأسرار بانتلام**: دوران الأسرار الدوري
4. **حدد الأذونات**: مبدأ الامتياز الأقل
5. **استخدم تكوينات خاصة بالبيئة**: تكوينات مختلفة لكل بيئة

### التطوير

1. **استخدم `.env.example`**: قالب للمتغيرات المطلوبة
2. **وثق المتغيرات**: أضف تعليقات تشرح كل متغير
3. **القيم الافتراضية**: قدم افتراضات معقولة حيثما كان آمناً
4. **التحقق من الصحة**: تحقق من متغيرات البيئة عند بدء التشغيل
5. **فحص النوع**: تأكد من أنواع البيانات الصحيحة

### الإنتاج

1. **تعيين جميع المتغيرات**: لا تعتمد على الافتراضات
2. **استخدم HTTPS**: لجميع عناوين URL الخارجية
3. **قييد المصادر**: حدد المصادر المسموح بها
4. **تمكين جميع الأمان**: لا تعطل ميزات الأمان
5. **مراقبة الاستخدام**: تتبع فعالية التكوين

## التحقق من الصحة

### التحقق عند بدء التشغيل

نفذ التحقق من صحة متغيرات البيئة عند بدء التطبيق:

```javascript
const requiredEnvVars = [
    'JWT_SECRET',
    'SESSION_SECRET',
    'POSTGRES_HOST',
    'POSTGRES_USER',
    'POSTGRES_PASSWORD'
];

requiredEnvVars.forEach(varName => {
    if (!process.env[varName]) {
        console.error(`متغير بيئة مطلوب مفقود: ${varName}`);
        process.exit(1);
    }
});
```

### المشاكل الشائعة

#### التطبيق لا يبدأ

1. تحقق من وجود ملف `.env`
2. تحقق من تعيين جميع المتغيرات المطلوبة
3. تحقق من أخطاء بناء الجملة في `.env`
4. تحقق من صحة قيم المتغيرات

#### فشل اتصال قاعدة البيانات

1. تحقق من `POSTGRES_HOST` و `POSTGRES_PORT`
2. تحقق من `POSTGRES_USER` و `POSTGRES_PASSWORD`
3. تأكد من إمكانية الوصول إلى قاعدة البيانات
4. تحقق من اتصال الشبكة

#### أخطاء CORS

1. تحقق من تعيين `ALLOWED_ORIGINS` بشكل صحيح
2. تحقق من تمكين `ENABLE_CORS`
3. تحقق من وجود عنوان URL الواجهة الأمامية في المصادر المسموح بها
4. تحقق من وحدة تحكم المتصفح للأخطاء المحددة

#### فشل اتصال GeoServer

1. تحقق من عنوان URL `GEOSERVER_TARGET`
2. تحقق من `GEOSERVER_USER` و `GEOSERVER_PASSWORD`
3. تأكد من إمكانية الوصول إلى GeoServer
4. تحقق من اتصال الشبكة

## اعتبارات الأمان

### إدارة الأسرار

1. **لا تقم أبداً بتشفير الأسرار**: استخدم دائماً متغيرات البيئة
2. **استخدم أدوات إدارة الأسرار**: فكر في استخدام خدمات vault
3. **دوران الأسرار بانتظام**: دوران الأسرار الدوري
4. **تدقيق الوصول**: راقب من لديه حق الوصول إلى الأسرار
5. **تخزين آمن**: تشفير الأسرار أثناء الراحة

### التحكم في الوصول

1. **حدد الوصول إلى `.env`**: قيد أذونات الملف
2. **سجلات التدقيق**: راقب الوصول إلى متغيرات البيئة
3. **كشف التغيير**: تنبيه عند تغييرات التكوين
4. **نسخ احتياطي للتكوينات**: احتفظ بنسخ احتياطية آمنة
5. **توثيق التغييرات**: تتبع تعديلات التكوين
