# 🚀 دليل تشغيل المشروع

## كيفية تشغيل السيرفرين بعد إعادة تشغيل اللابتوب

### الخيار 1: تشغيل السيرفرين معاً (موصى به)

افتح Visual Studio Code وانتقل إلى مجلد PSM:
```bash
cd c:\xampp\htdocs\realestate-map\WEB\PSM
```

ثم اكتب:
```bash
npm run dev
```

هذا سيقوم بتشغيل:
- ✅ السيرفر الخلفي (3000)
- ✅ السيرفر الأمامي (5173 أو 5174)

### الخيار 2: تشغيل السيرفرين بشكل منفصل

#### تشغيل السيرفر الخلفي فقط:
```bash
cd c:\xampp\htdocs\realestate-map\WEB\PSM
npm run start:backend
# أو
node server.js
```

#### تشغيل السيرفر الأمامي فقط:
```bash
cd c:\xampp\htdocs\realestate-map\WEB\PSM\frontend-react
npm run dev
```

### الخيار 3: تشغيل السيرفر الخلفي فقط (للتطوير)
```bash
cd c:\xampp\htdocs\realestate-map\WEB\PSM
npm start
```

## 🌐 الروابط بعد التشغيل

### السيرفر الخلفي:
- http://localhost:3000

### السيرفر الأمامي:
- http://localhost:5173 (أو 5173 إذا كان مشغولاً)
- http://localhost:5174 (بديل إذا كان 5173 مشغولاً)

## 📝 ملاحظات مهمة

1. **يجب تشغيل السيرفرين معاً**:
   - السيرفر الخلفي (3000): للـ API وقاعدة البيانات
   - السيرفر الأمامي (5173/5174): للواجهة والخريطة

2. **بعد إعادة تشغيل اللابتوب**:
   - افتح Visual Studio Code
   - انتقل إلى مجلد PSM
   - اكتب `npm run dev`

3. **إذا كنت تستخدم nodemon**:
   ```bash
   npm install -g nodemon
   nodemon server.js
   ```

## 🛠️ أوامر npm المتاحة

```bash
npm run dev          # تشغيل السيرفرين معاً
npm start            # تشغيل السيرفر الخلفي فقط
npm run start:backend # تشغيل السيرفر الخلفي فقط
npm run start:frontend # تشغيل السيرفر الأمامي فقط
```

## 🔧 حل المشاكل

### إذا لم يعمل المنفذ 5173:
- سيستخدم Vite المنفذ 5174 تلقائياً
- أو يمكنك إيقاف العملية التي تستخدم 5173

### إذا لم يعمل المنفذ 3000:
- تحقق من أن السيرفر الخلفي يعمل
- تحقق من أن المنفذ 3000 ليس مشغولاً

## 📚 للتعديل المستقبلي

1. **عدّل الملفات في frontend-react**
2. **اختبر التعديل**
3. **انسخ التعديل إلى المجلد الأصلي** (إذا كنت تستخدم الخيار الثالث)
4. **أرسل إلى GitHub**:
   ```bash
   git add .
   git commit -m "وصف التعديل"
   git push
   ```
