# توثيق واجهة برمجة التطبيقات (API Documentation)

## نظرة عامة

يقدم هذا المستند توثيقاً شاملاً لجميع نقاط نهاية واجهة برمجة التطبيقات REST في منصة خريطة خدمات فلسطين. جميع نقاط النهاية تُرجع استجابات JSON وتتبع رموز حالة HTTP القياسية.

## الرابط الأساسي (Base URL)

- **التطوير**: `http://localhost:3000`
- **الإنتاج**: `https://yourdomain.com`

## المصادقة (Authentication)

تتطلب معظم نقاط النهاية المصادقة عبر رمز JWT. قم بتضمين الرمز في ترويسة التفويض:

```
Authorization: Bearer <your_jwt_token>
```

لنقاط نهاية المسؤول، قم بتضمين معرف مستخدم المسؤول:

```
x-admin-user-id: <admin_user_id>
```

## تنسيق الاستجابة

### استجابة النجاح
```json
{
  "success": true,
  "data": { ... }
}
```

### استجابة الخطأ
```json
{
  "success": false,
  "error": "رسالة الخطأ",
  "details": "معلومات تفصيلية عن الخطأ"
}
```

## نقاط نهاية واجهة برمجة التطبيقات

### نقاط نهاية المصادقة

#### تسجيل مستخدم جديد
- **نقطة النهاية**: `POST /api/auth/register`
- **المصادقة**: لا يوجد
- **تحديد المعدل**: نعم (authLimiter)
- **نص الطلب**:
```json
{
  "name": "الاسم الكامل",
  "email": "user@example.com",
  "phone": "059xxxxxxx",
  "password": "كلمةمرورآمنة",
  "role": "user"
}
```
- **الاستجابة**:
```json
{
  "success": true,
  "message": "تم تسجيل الحساب بنجاح",
  "user": {
    "user_id": 123,
    "full_name": "الاسم الكامل",
    "email": "user@example.com",
    "phone": "059xxxxxxx",
    "role": "user"
  }
}
```
- **الأخطاء**:
  - 400: بيانات إدخال غير صالحة
  - 409: البريد الإلكتروني أو الهاتف موجود بالفعل
  - 500: خطأ في الخادم

#### تسجيل الدخول
- **نقطة النهاية**: `POST /api/auth/login`
- **المصادقة**: لا يوجد
- **تحديد المعدل**: نعم (authLimiter)
- **نص الطلب**:
```json
{
  "email": "user@example.com",
  "phone": "059xxxxxxx",
  "password": "كلمةمرورآمنة"
}
```
- **الاستجابة**:
```json
{
  "success": true,
  "token": "jwt_token_here",
  "user": {
    "user_id": 123,
    "full_name": "الاسم الكامل",
    "email": "user@example.com",
    "phone": "059xxxxxxx",
    "role": "user"
  }
}
```
- **الأخطاء**:
  - 400: بيانات الاعتماد غير صالحة
  - 401: فشل المصادقة
  - 429: محاولات تسجيل دخول كثيرة جداً
  - 500: خطأ في الخادم

### نقاط نهاية طلبات الخدمة

```json
  "service_type": "نجار"
}
```
- **الاستجابة**:
```json
{
  "success": true,

  "status": "pending"

```
- **الأخطاء**:

  - 400: لا يمكن طلب خدمة من نفسك
  - 500: خطأ في الخادم

#### الحصول على طلبات الخدمة
- **نقطة النهاية**: `GET /api/service-requests`
- **المصادقة**: مطلوبة
- **معاملات الاستعلام**:
  - `user_id`: معرف المستخدم (للطلبات المرسلة من المستخدم)
  - `provider_user_id`: معرف مستخدم المزود (للطلبات المستلمة من المزود)
  - `status`: تصفية حسب الحالة (pending, accepted, rejected, completed)
- **الاستجابة**:
```json
{
  "success": true,
  "requests": [
    {
      "id": 456,
      "user_id": 123,
      "provider_user_id": 456,
      "service_type": "نجار",
      "status": "pending",
      "created_at": "2026-07-29T12:00:00Z"
    }
  ]
}
```
- **الأخطاء**:
  - 400: user_id أو provider_user_id مفقود
  - 500: خطأ في الخادم

## أحداث Socket.io

### أحداث العميل ← السيرفر

#### الاتصال
```javascript
socket.emit('connection', { user_id: 123 });
```

#### قطع الاتصال
تلقائي عند قطع اتصال العميل

### أحداث السيرفر ← العميل

#### طلب خدمة جديد
```javascript
socket.on('service_request_new', (data) => {
  // data: { id, requestId, serviceType, createdAt }
});
```

#### رد طلب الخدمة
```javascript
socket.on('service_request_response', (data) => {
  // data: { requestId, status, serviceType, providerName }
});
```

#### رسالة طلب الخدمة
```javascript
socket.on('service_request_message', (data) => {
  // data: { requestId, message }
});
```

#### إتمام طلب الخدمة
```javascript
socket.on('service_request_completed', (data) => {
  // data: { requestId, providerPhone, providerWhatsapp } (للمستخدم)
  // data: { requestId, userPhone, userWhatsapp } (للمزود)
});
```

#### إجبار إعادة تسجيل الدخول
```javascript
socket.on('force_relogin', (data) => {
  // data: { message: "تم تحديث حسابك من قبل الإدارة" }
});
```
