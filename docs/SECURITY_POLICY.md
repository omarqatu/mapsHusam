# سياسة الأمان (Security Policy)

## نظرة عامة

يحدد هذا المستند تدابير الأمان الشاملة المنفذة في منصة خريطة خدمات فلسطين. يغطي المصادقة، التفويض، حماية البيانات، أمان الشبكة، وأفضل الممارسات للحفاظ على نظام آمن.

## أمان المصادقة

### أمان كلمة المرور

#### تجزئة كلمة المرور

- **الخوارزمية**: bcrypt
- **جولات الملح**: 10
- **دعم الترحيل**: الترحيل التلقائي من النص العادي إلى bcrypt
- **التنفيذ**:

```javascript
const BCRYPT_SALT_ROUNDS = 10;
const hashedPassword = await bcrypt.hash(plainPassword, BCRYPT_SALT_ROUNDS);
```

#### ترحيل كلمة المرور

يدعم النظام الترحيل التلقائي من كلمات المرور النصية القديمة:

```javascript
async function verifyPasswordWithMigration(plainPassword, storedValue) {
    if (BCRYPT_HASH_REGEX.test(storedValue)) {
        const valid = await bcrypt.compare(plainPassword, storedValue);
        return { valid, needsRehash: false };
    }
    
    // مقارنة النص العادي القديم
    const valid = plainPassword === storedValue;
    return { valid, needsRehash: valid };
}
```

#### سياسة كلمة المرور

**التنفيذ الحالي**:
- الحد الأدنى للطول: غير مفروض (يجب تنفيذه)
- التعقيد: غير مفروض (يجب تنفيذه)
- الانتهاء: غير منفذ (يجب تنفيذه)

**سياسة الإنتاج الموصى بها**:
- الحد الأدنى للطول: 8 أحرف
- التعقيد: حرف كبير واحد على الأقل، حرف صغير واحد، رقم واحد، حرف خاص واحد
- الانتهاء: 90 يوماً
- التاريخ: منع إعادة استخدام آخر 5 كلمات مرور
- القفل: 5 محاولات فاشلة، قفل لمدة 15 دقيقة

### أمان رمز JWT

#### تكوين الرمز

- **الخوارزمية**: HS256
- **السر**: متغير البيئة `JWT_SECRET`
- **الانتهاء**: غير محدد صراحة (يجب تكوينه)
- **التخزين**: جانب العميل (localStorage)

**التنفيذ الحالي**:

```javascript
const token = jwt.sign(
    { user_id: user.user_id, role: user.role },
    process.env.JWT_SECRET
);
```

**تكوين الإنتاج الموصى به**:
- الانتهاء: 15 دقيقة لرموز الوصول
- رموز التحديث: انتهاء صلاحية 7 أيام
- تدوير الرمز: تنفيذ آلية رمز التحديث
- التخزين الآمن: ملفات تعريف الارتباط HttpOnly

#### التحقق من الرمز

```javascript
function verifyToken(token) {
    try {
        const decoded = jwt.verify(token, process.env.JWT_SECRET);
        return { valid: true, decoded };
    } catch (error) {
        return { valid: false, error: error.message };
    }
}
```

### إدارة الجلسة

#### التحقق من الجلسة

- **نقطة النهاية**: `/api/auth/verify-session`
- **تسجيل الخروج بالقوة**: يمكن للمسؤول تسجيل خروج أي مستخدم بالقوة
- **التنفيذ**:

```javascript
app.post('/api/auth/verify-session', async (req, res) => {
    const { user_id } = req.body;
    
    const result = await servicesPool.query(
        'SELECT force_logout_flag FROM users WHERE user_id = $1',
        [user_id]
    );
    
    if (result.rows[0]?.force_logout_flag) {
        return res.json({ valid: false, force_logout: true });
    }
    
    return res.json({ valid: true, force_logout: false });
});
```

#### مهلة الجلسة

**الحالة الحالية**: غير منفذ
**التوصية**: تنفيذ مهلة جلسة 30 دقيقة من عدم النشاط

## أمان التفويض

### التحكم في الوصول القائم على الأدوار (RBAC)

#### التسلسل الهرمي للأدوار

1. **المسؤول**: وصول كامل للنظام
2. **المزود**: قدرات مقدم الخدمة
3. **المستخدم**: قدرات المستخدم العادي

#### تنفيذ الأذونات

```javascript
function requireAdmin(req, res, next) {
    const adminUserId = req.headers['x-admin-user-id'];
    
    servicesPool.query(
        'SELECT role FROM users WHERE user_id = $1',
        [adminUserId],
        (err, result) => {
            if (err || result.rows[0]?.role !== 'admin') {
                return res.status(403).json({ 
                    success: false, 
                    error: 'غير مصرح به كمسؤول' 
                });
            }
            next();
        }
    );
}
```

## أمان الشبكة

### تكوين CORS

#### التنفيذ الحالي

```javascript
const ALLOWED_ORIGINS = process.env.ALLOWED_ORIGINS
    ? process.env.ALLOWED_ORIGINS.split(',').map(o => o.trim())
    : null;

function corsOriginCheck(origin, callback) {
    if (!origin || !ALLOWED_ORIGINS) return callback(null, true);
    if (ALLOWED_ORIGINS.includes(origin)) return callback(null, true);
    return callback(new Error('CORS غير مسموح'));
}

app.use(cors({
    origin: corsOriginCheck,
    credentials: true
}));
```

**التوصية**:
- تعيين `ALLOWED_ORIGINS` دائماً في الإنتاج
- استخدام نطاقات محددة بدلاً من أحرف البدل
- تنفيذ التخزين المؤقت لـ CORS preflight
- النظر في استخدام وكيل CORS للتطوير

### رؤوس الأمان

#### تكوين Helmet.js

```javascript
if (process.env.ENABLE_HELMET !== 'false') {
    app.use(helmet({
        contentSecurityPolicy: false, // معطل لتوافق GeoServer
        hsts: {
            maxAge: 31536000,
            includeSubDomains: true,
            preload: true
        }
    }));
}
```

**الرؤوس الحالية**:
- HSTS: مكن (سنة واحدة)
- CSP: معطل (توافق GeoServer)
- X-Frame-Options: افتراضي
- X-Content-Type-Options: افتراضي

**التوصية**:
- إعادة تمكين CSP مع استثناءات GeoServer المناسبة
- إضافة X-Frame-Options: DENY
- إضافة X-Content-Type-Options: nosniff
- إضافة Referrer-Policy: strict-origin-when-cross-origin

- إضافة تحديد المعدل لجميع نقاط نهاية واجهة برمجة التطبيقات
- تنفيذ التراجع التدريجي
- إضافة رؤوس تحديد المعدل إلى الاستجابات

## أمان البيانات

### التشفير

#### البيانات أثناء الراحة

**الحالة الحالية**: غير منفذ
**التوصية**:
- تشفير الحقول الحساسة في قاعدة البيانات
- استخدام دوال تشفير PostgreSQL
- تنفيذ تشفير البيانات الشفاف (TDE)

#### البيانات أثناء النقل

**الحالة الحالية**: تعتمد على النشر
**التوصية**:
- فرض HTTPS في الإنتاج
- استخدام TLS 1.2 أو أعلى
- تنفيذ تثبيت الشهادات
- تعطيل التشفيرات الضعيفة

### معالجة البيانات الحساسة

#### أرقام الهاتف

- مخزنة كنص عادي (يجب تشفيرها)
- مكشوفة في استجابات واجهة برمجة التطبيقات (يجب إخفاؤها)
- لا يوجد تنسيق تحقق (يجب تنفيذه)

#### عناوين البريد الإلكتروني

- مخزنة كنص عادي
- قيد التفرد مفروض
- لا يوجد تحقق من البريد الإلكتروني (يجب تنفيذه)

#### كلمات المرور

- مجزأة بـ bcrypt
- جولات الملح: 10
- دعم الترحيل لكلمات المرور القديمة

## أفضل الممارسات

### التطوير

1. **لا تلتزم أبداً بالأسرار**: استخدم متغيرات البيئة
2. **استخدم HTTPS في التطوير**: الاستعداد للإنتاج
3. **نفذ الأمان مبكراً**: الأمان بالتصميم
4. **تدقيقات أمان منتظمة**: مراجعات أمان دورية
5. **حافظ على تحديث التبعيات**: تحديثات التبعيات المنتظمة

### الإنتاج

1. **مكن جميع ميزات الأمان**: لا تعطل للراحة
2. **استخدم أسراراً قوية**: أسرار عشوائية طويلة
3. **نفذ المراقبة**: مراقبة الأمان في الوقت الفعلي
4. **نسخ احتياطي منتظم**: أنظمة نسخ احتياطي آلية
5. **خطة الاستجابة للحوادث**: الاستعداد لحوادث الأمان

### النشر

1. **تكوين آمن**: إعدادات خاصة بالإنتاج
2. **عزل الشبكة**: أجزاء الشبكة المنفصلة
3. **قواعد جدار الحماية**: تقييد الوصول إلى الشبكة
4. **شهادات SSL/TLS**: شهادات صالحة
5. **تحديثات منتظمة**: إدارة تصحيحات الأمان
