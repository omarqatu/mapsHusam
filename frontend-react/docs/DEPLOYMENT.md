# النشر

## بناء الواجهة

من `frontend-react`:

```bash
npm install
npm run build
```

ينتج Vite مجلد `dist` الذي يحتوي الصفحة المبنية ونسخة ملفات `public`. انشر `dist` في خدمة الملفات الثابتة أو المسار الذي يقدمه IIS/Node.

## تشغيل الخادم

من مجلد `PSM` الأب:

```bash
npm install
npm start
```

يجب ضبط `.env` وقاعدة البيانات وGeoServer وCORS قبل الإنتاج.

## بعد النشر

اختبر:

- تسجيل الدخول وتحقق الجلسة.
- الخريطة والبحث بدون خريطة.
- APIs البحث والتقييمات ومزود الخدمة.
- الهاتف والتابلت عموديًا وأفقيًا.
- HTTPS وGPS والإشعارات والروابط الخارجية.

`dist` ناتج بناء وليس نسخة احتياطية. لا تنسخه يدويًا من تغييرات جزئية؛ أعد تشغيل `npm run build`.
