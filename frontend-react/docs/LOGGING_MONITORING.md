# التسجيل والمراقبة

## الواجهة

الكود الحالي يستخدم `console.log` و`console.warn` و`console.error` للتشخيص، خصوصًا في الخريطة وطلبات API والموبايل. لا تسجل كلمات مرور أو tokens أو إحداثيات حساسة بلا حاجة.

## الخادم

`server.js` يكتب سجلات تشغيل وطلبات وأخطاء عبر console. يمكن ربطه لاحقًا بأداة إدارة عمليات أو نظام مركزي، لكن لا تعتبر Winston أو PM2 أو metrics مفعلة ما لم تُضف وتُختبر فعليًا.

## ما يجب تسجيله

- وقت الطلب والمسار وحالة الاستجابة.
- مدة عمليات البحث والـ GeoServer.
- فشل قاعدة البيانات دون بيانات اعتماد.
- أخطاء GPS أو WebView بصورة عامة.

## ما يجب مراقبته في الإنتاج

- توفر الخادم وقاعدة البيانات وGeoServer.
- معدل أخطاء 4xx و5xx.
- زمن البحث وتحميل الخريطة.
- الاتصالات المتقطعة وSocket.io.
- مساحة القرص وسجلات الخادم.
