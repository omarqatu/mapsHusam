# الأداء

## تحسينات موجودة

- تأجيل بعض تحديثات المقاسات باستخدام `requestAnimationFrame` في أنظمة الموبايل.
- تحديث حجم الخريطة عند تغيير مساحة اللوحات.
- استخدام cache محدود لبعض خدمات React.
- تقليل الحركة والصور في الشاشات الصغيرة.
- تقسيم ملفات JavaScript حسب الوظيفة بدل ملف واحد ضخم.

## قواعد عملية

- لا تطلب API داخل كل تغيير لوحة مفاتيح دون debounce.
- لا تنفذ تحديث DOM داخل كل حدث touch أو resize؛ استخدم throttle أو requestAnimationFrame.
- لا تحمل طبقات أو صورًا غير مطلوبة للصفحة.
- راقب حجم `dist` ووقت تحميل الخريطة.

## ما لم يُثبت بعد

لا توجد أرقام أداء أو أهداف p95 موثقة، ولا يوجد Redis أو نظام cache خادم موثق داخل مشروع الواجهة. لا تذكر أرقامًا قياسية قبل قياسها على أجهزة وشبكات حقيقية.
