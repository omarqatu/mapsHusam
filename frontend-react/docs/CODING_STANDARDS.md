# معايير البرمجة

## قاعدة عامة

حافظ على أسلوب الملف الموجود. المشروع يجمع JavaScript تقليديًا وReact، لذلك لا تفرض إعادة تنسيق شاملة على ملفات قديمة.

## JavaScript

- استخدم أسماء واضحة ولا تستخدم متغيرات من حرف واحد.
- تحقق من القيم القادمة من DOM وAPI.
- استخدم `const` و`let` بدل `var` في الكود الجديد.
- لا تضع أسرارًا في العميل.
- احفظ API العامة مثل `window.requestGeolocationPosition` و`window.MobileAppBridge`.
- استخدم fallback عند تعديل bridge أو ملفات public الحساسة.

## CSS وHTML

- حافظ على RTL والوصول باللمس.
- ضع قواعد responsive في ملف الصفحة أو الملف المتخصص.
- اختبر عدم تداخل النصوص والأزرار.
- استخدم معرفات وعناصر موجودة بدل إنشاء نسخ موازية بلا ضرورة.

## React

- التزم بنمط React الموجود داخل `src`.
- ضع API والوظائف المشتركة في `src/services`.
- لا تفترض أن تعديل React يغيّر صفحات `public` ما لم يوجد ربط صريح.

## التوثيق

أي endpoint أو صلاحية أو إعداد يجب أن يطابق الكود الفعلي، ويجب تمييز المخطط المستقبلي عن السلوك المطبق.
