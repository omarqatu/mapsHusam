# وحدة نظم المعلومات الجغرافية

## الأدوات

- OpenLayers داخل `public/ol`.
- Proj4 داخل `public/proj4`.
- نظام الإحداثيات الفلسطيني EPSG:28191.
- GeoServer للطبقات الخارجية من خلال إعدادات الخادم.

## الطبقات

يوجد فصل بين:

- طبقات العقارات مثل `ApartRent` و`ApartSale` و`LandSale`.
- طبقات الخدمات الموحدة التي تُقرأ من `service_all` مع `discriminator`.
- طبقات مساعدة مثل الموقع والطرق والإبرازات المؤقتة.

راجع `public/js/layers.js` و`config.js` قبل إضافة طبقة جديدة، لأن اسم العرض قد يختلف عن اسم قاعدة البيانات.

## التعديل والتحرير

ملفات `edit-core.js` و`edit-wfs.js` وملفات تحرير المضلع والخط تتعامل مع WFS-T وخصائص المعالم. لا تخلط بين `id` للخدمات و`fid` لبعض طبقات العقارات.

## الموبايل

`mobile-tabs.js` لا يغير الخريطة نفسها؛ يعيد ترتيب عرض اللوحات ويستدعي `map.updateSize()` عند تغيير مساحة الخريطة. يجب اختبار التكبير، السحب، اللوحات، ودقة GPS على الاتجاهين.
