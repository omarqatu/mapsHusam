# قاعدة البيانات

## قواعد البيانات

بحسب إعدادات الخادم، توجد قاعدة خدمات وقاعدة عقارات منفصلتان:

- `services_db`: المستخدمون، الخدمات الموحدة، الطلبات، التقييمات والإشعارات.
- `realestate`: طبقات العقارات عند فصلها عن الخدمات.

## الجداول والمفاهيم المهمة

- `public.users`: الحسابات والأدوار وربط مزود الخدمة بالطبقة والمعرف.
- `public.service_all`: جدول الخدمات الموحد، ويستخدم `discriminator` لتمييز نوع الخدمة.
- طبقات العقارات: تستخدم معرفات العقار وحقولها الخاصة.
- جداول طلبات الخدمة والتقييمات والرسائل: يديرها الخادم حسب مخطط قاعدة البيانات الفعلي.

## الحالة والموقع

- `status=0` يعني متوفر يدويًا.
- `status=1` يعني غير متوفر.
- `auto_status` قيمة مشتقة تستخدمها نتائج الخريطة والبحث، وقد يحسبها trigger بناءً على الحالة وساعات العمل وتاريخ الانتهاء.
- `x_coord` و`y_coord` إحداثيات فلسطينية بنظام EPSG:28191.

## مصدر الحقيقة

لا تُنشئ أو تغيّر جدولًا اعتمادًا على هذا الملف وحده. راجع SQL الموجود في `PSM/database` واتصال الخادم قبل أي migration، وخذ نسخة احتياطية قبل التغييرات البنيوية.
