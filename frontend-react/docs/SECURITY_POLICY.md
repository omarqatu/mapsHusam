# سياسة الأمان

## الواجهة

- لا تضع كلمات مرور أو مفاتيح API سرية داخل `public` أو `src`.
- عالج النصوص القادمة من المستخدم عبر escaping أو `textContent` قبل إدخالها إلى HTML.
- افحص الروابط الخارجية قبل فتحها، واستخدم `noopener` عند فتح نافذة جديدة.
- تعامل مع GPS كبيانات حساسة ولا تخزنها أكثر مما يلزم.
- لا تعتبر `localStorage` مكانًا آمنًا للأسرار.

## الخادم

الخادم في `PSM/server.js` مسؤول عن CORS وHelmet وrate limiting والمصادقة والتحقق من الصلاحيات حسب إعدادات البيئة. يجب مراجعة إعدادات الإنتاج بدل افتراض أن إعداد التطوير آمن.

## الأسرار

- ملف `.env` يبقى خارج المستودع العام.
- لا تسجل كلمات المرور أو tokens أو بيانات الاتصال في console.
- بدّل الأسرار الافتراضية قبل النشر.
- استخدم HTTPS في الإنتاج، خصوصًا عند تشغيل GPS أو WebView.

## البلاغات

عند ظهور خطأ، سجّل المسار والوقت ورقم الطلب دون تسجيل payload حساس. أصلح السبب في الخادم أو العميل، ولا تخفِ الخطأ برسالة نجاح وهمية.
