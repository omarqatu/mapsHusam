# سجل التغييرات

## النسخة الأولى الحالية - 2026-09

- تثبيت بنية Vite وReact داخل `frontend-react`.
- الحفاظ على صفحات `public` متعددة الصفحات للخريطة والبحث والإدارة.
- دعم الخريطة في الهاتف والتابلت عبر `mobile-tabs.js` و`mobile-tabs.css`.
- دعم البحث بدون خريطة عبر `no-map-mobile.js` حتى 1024px.
- إضافة `mobile-app-bridge.js` لعقد WebView المستقبلي.
- توثيق لوحة مزود الخدمة وحالات `status=0` و`status=1`.
- توثيق Widgets والبيانات اليدوية وOpen-Meteo وAladhan.
- تحديث ملفات `docs` لتصف التنفيذ الحالي بدل البنية المفترضة.

## طريقة تسجيل التغيير

أضف تاريخًا ووصفًا مختصرًا عند تغيير API أو صفحة أو قاعدة بيانات أو سلوك موبايل. اربط التغيير بالملف الفعلي، واذكر إن كان يحتاج migration أو إعادة بناء `dist`.
