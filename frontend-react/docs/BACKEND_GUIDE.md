# دليل الخادم الخلفي

للدليل الموحد الذي يربط الخادم بالواجهة وقاعدة البيانات والنشر راجع [FULL_PROJECT_GUIDE.md](FULL_PROJECT_GUIDE.md).

## موقع الخادم

الخادم ليس داخل `frontend-react`؛ ملفه هو:

```text
PSM/server.js
```

وملف إعداداته وحزمته موجودان في مجلد `PSM` الأب.

## التشغيل

من مجلد `PSM` الأب:

```bash
npm start
```

الخادم يقرأ `.env`، يشغل Express، يتصل بـ PostgreSQL، ويوفر APIs وSocket.io وGeoServer proxy.

## مسؤوليات الخادم

- المصادقة والجلسات وتغيير كلمة المرور.
- البحث وإرجاع معالم الخدمات والعقارات.
- ربط مزودي الخدمة بالمعالم وتحديث `status` والموقع.
- التقييمات وطلبات الخدمة والدردشة والإشعارات.
- إحصائيات المنصة وبيانات Widgets.
- تمرير طلبات GeoServer من خلال `/geoserver-proxy`.

## ملاحظات مطابقة مهمة

- الخادم الفعلي هو `PSM/server.js` في المجلد الأب، وليس جزءًا من حزمة React.
- مسارات الإدارة تستخدم JWT في ترويسة `Authorization: Bearer`.
- جلسة مشاهدة المستخدم للمشرف من نوع `readonly_view` مؤقتة وتسمح بالقراءة فقط.
- راجع `database/` و`server.js` قبل اعتماد أي مثال SQL أو اسم حقل.

## قاعدة مهمة

لا تضع أسرار PostgreSQL أو JWT أو GeoServer داخل `frontend-react` أو `public`. الواجهة تستدعي المسارات فقط، والخادم يملك الأسرار والتحقق والصلاحيات.
