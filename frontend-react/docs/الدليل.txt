دليل وثائق المشروع
===================

وثائق نطاق المشروع:
- PROJECT_OVERVIEW.md - نظرة عامة على الصفحات والتقنيات والأوامر
- SYSTEM_ARCHITECTURE.md - البنية الحالية وحدود React وpublic والخادم
- FRONTEND_GUIDE.md - تطوير صفحات الخريطة والبحث بدون خريطة
- BACKEND_GUIDE.md - موقع server.js وتشغيل الخادم ومسؤولياته
- API_DOCUMENTATION.md - مسارات API المستخدمة بين الواجهة والخادم
- DATABASE_SCHEMA.md - قواعد البيانات والجداول ومفهوم status/auto_status
- GIS_MODULE.md - OpenLayers وProj4 وGeoServer وEPSG:28191

وثائق التشغيل والصيانة:
- USER_ROLES.md - الأدوار وصلاحيات مزود الخدمة والمستخدم والمشرف
- SECURITY_POLICY.md - أمان الواجهة والخادم والأسرار
- CONFIGURATION.md - إعداد Vite وWidgets والخادم
- ENVIRONMENT_VARIABLES.md - متغيرات بيئة الواجهة والخادم
- DEPLOYMENT.md - البناء والنشر والتشغيل
- ERROR_HANDLING.md - معالجة أخطاء الواجهة والخادم
- TESTING_GUIDE.md - الاختبارات اليدوية وحالة الاختبارات الآلية
- CODING_STANDARDS.md - قواعد كتابة وتعديل الكود
- PERFORMANCE.md - تحسينات الأداء والقياس
- LOGGING_MONITORING.md - التسجيل والمراقبة
- CHANGELOG.md - سجل النسخة الأولى والتغييرات

وثائق إضافية خارج مجلد docs:
- ../MOBILE-APP-READINESS.md - جاهزية WebView وتطبيق الموبايل
- ../src/services/README.md - طبقة خدمات React الحالية
- ../public/WIDGETS-API-DOCUMENTATION.md - نظام المعلومات الحية وWidgets

المصدر الحقيقي للتنفيذ هو الكود، خصوصًا public وsrc وserver.js في المجلد الأب. إذا تعارضت وثيقة مع الكود، يجب تحديث الوثيقة أو اعتماد الكود بعد التحقق منه.
