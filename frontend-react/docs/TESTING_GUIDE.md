# دليل الاختبار

## الحالة الحالية

لا توجد حاليًا scripts اختبار آلي في `package.json`. الفحوصات المتاحة هي بناء Vite وفحص الأخطاء وصحة الخادم عند تشغيله.

## فحص الواجهة

```bash
npm run build
```

ثم اختبر النسخة الناتجة أو `npm run dev`.

## قائمة اختبار الخريطة

- تحميل الخريطة والطبقات الأساسية.
- البحث السريع والبحث بالموقع.
- فتح النتائج والنوافذ المنبثقة.
- التعديل إن كان الحساب مخولًا.
- لوحة مزود الخدمة وحالات `status=0/1`.
- الهاتف والتابلت بالاتجاهين.

## قائمة اختبار البحث بدون خريطة

- الفئات والتنقل بينها.
- البحث العلوي والفلاتر.
- بطاقات النتائج والاتصال وواتساب وطلبات الخدمة.
- Widgets والتقييمات والوسائط.
- عرض عمود واحد للهاتف وعمودين للتابلت.

## التطبيق الأصلي لاحقًا

اختبر WebView، زر الرجوع، لوحة المفاتيح، GPS المرفوض والمسموح، الإشعارات، safe area، الشبكة البطيئة والروابط الخارجية.
